# Public source discovery batches

Files in this directory are discovery manifests, not published MCP records.

Each record must pass archive-identifier, historical, language, claim-context, and item-level rights review before it is inserted into the public catalog. A URL being publicly viewable does not grant redistribution rights.

The Japanese Ministry of Foreign Affairs record is intentionally stored as an institutional claim with `pending_review` assessment and `requiresCounterEvidence: true`. It must not be published alone.
